# 책 문제 경계 목록

이 문서는 사용자가 제공한 『코딩 테스트 합격자 되기 자바편』 목차 사진에서 확인한 문제의 분류, 제목과 별 개수만 기록한다. 별은 책의 난이도 표시이며 Programmers 공식 레벨을 뜻하지 않는다.

Algorithm Bridge 문제는 아래 문제들과 별개로 푼다. 아래 문제의 이름만 바꾸거나 입력·출력과 풀이 구조를 사실상 그대로 사용하지 않는다. 문제 본문, 해설과 정답은 이 문서에 저장하지 않는다.

금요일 라이브 코딩에서는 각 주제의 모의테스트 중 별이 가장 적은 문제들을 우선 후보로 삼는다. 같은 최저 별 개수를 가진 문제가 여러 개면 모두 후보로 남긴다.
